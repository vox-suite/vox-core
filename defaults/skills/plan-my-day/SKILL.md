1. Identify the user's timezone, fixed commitments, available time and highest priorities. Clarify consequential ambiguity.
2. Use supplied commitments first. Discover calendar capabilities only when the user asks for calendar-backed planning and use only current grants.
3. Allocate realistic durations, breaks and transition time. Explain conflicts and prioritize rather than inventing free time.
4. Return a proposed schedule with timezone and a short list of flexible alternatives.
Completion: the plan fits known commitments and states missing information. This guidance creates no calendar event or reminder.
