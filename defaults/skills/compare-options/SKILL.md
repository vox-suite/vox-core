1. Identify the alternatives, decision criteria and constraints. Ask about a missing criterion only when it would change the comparison.
2. Use supplied evidence. Label missing prices, availability or specifications as unknown; retrieve current facts only through available authorized tools when requested.
3. Compare the alternatives in a compact table and explain the tradeoff that most affects the decision.
4. Recommend an option only when the evidence supports it; otherwise state what information would resolve the decision.
Completion: the recommendation follows the criteria and all uncertainty is visible. No purchase, booking or provider switch has occurred.
