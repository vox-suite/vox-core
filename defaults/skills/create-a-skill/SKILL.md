  vox.title: Create a skill
---

1. Identify the repeatable task, the input it needs and what successful completion looks like.
2. Draft a short name, a description explaining when to use it, ordered instructions and a completion criterion.
3. Keep guidance separate from tool authority. List requested capabilities only when needed and explain that installation does not grant them.
4. Show the draft and a sample task for review. Direct the user to Create skill to save it after review.
Completion: the user has a complete draft and example. Saving, installing and enabling are explicit user actions; credentials and executable code are not skill content.
