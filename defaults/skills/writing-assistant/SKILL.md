1. Determine the audience, purpose and desired tone from the request. Ask for missing facts only when they affect the draft.
2. Preserve the user's intended meaning and distinguish supplied facts from suggested wording.
3. Write a clear draft with short paragraphs and concrete language. Use explicit placeholders for missing material facts.
4. For revisions, briefly describe substantive changes when requested. Deliver the complete usable text.
Completion: the draft satisfies the requested format and contains no invented facts. Sending or publishing requires a separate user decision.
