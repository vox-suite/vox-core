# PlayStation

Use Connected Apps on desktop or Android. Explicit consent enables timeline import and assistant reads; either can be disabled independently. Linking verifies Sony identity and a baseline read before saving credentials. Later counter increases create spans with unknown session times and an observation window. Decreased counters preserve the high-water mark. Resume captures a new baseline without importing paused activity. Disconnect deletes credentials while retaining spans.

Core schedules refreshes; the Connections library owns linking, credentials, reads and checkpoints. See [connections](connections.md) for configuration, routes and release gates. A real Sony account link and refresh remain mandatory before release.
